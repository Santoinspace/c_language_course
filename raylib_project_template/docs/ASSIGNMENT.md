# C 语言程序设计基础 · 期末大作业

## 一、任务目标

使用 **C99 + raylib 6.0 + CMake + Git** 完成一个可独立运行的小游戏或图形化小应用。重点是 C 基础知识，不涉及复杂引擎技巧、网络服务或现成算法库的调用。

## 二、必备技术要求

1. 只用 C 语言编写业务代码；必须包含入口文件及 **至少 2 个自己编写的业务 `.c` 文件**，用 `.h` 声明模块接口；所有新增 `.c` 必须明确加入 `CMakeLists.txt`。
2. 使用结构体组织至少一种实体数据，使用数组存储数据或状态，至少一个函数通过指针参数修改数据。
3. 至少实现一种标准 C 文件读写（保存分数、读取题库、保存商品库存、导入统计数据等）；处理文件不存在或格式错误的情形。
4. 有基本图形界面与键盘/鼠标交互；raylib 是唯一指定窗口与图形依赖。
5. 必须能在规定的 Windows 11 / MinGW-w64 / CMake / mingw32-make 环境中，从源码成功配置、编译、运行。
6. 至少 5 次有实质内容、可解释的 Git commit。至少一次提交涉及 CMake 多文件配置。
7. 提交 `README.md`，说明功能、运行方式、源文件职责、操作手册、测试方法和已知问题。

**不要求**：联网联机、数据库、摄像头车牌识别、C++、Qt、复杂图片素材。AI 辅助与代码引用遵循学院课程规定，应在 README 中说明引用或外部资源。

## 三、建议题目与最低功能

| 题目       | 最低功能                                      | 扩展功能（非必需） |
| ---------- | --------------------------------------------- | ------------------ |
| 贪吃蛇     | 转向、增长、碰撞、计分、最高分持久化          | 难度、暂停、障碍物 |
| 俄罗斯方块 | 下落、移动旋转、消行、计分、结束判断          | 预览下一个方块     |
| 五子棋     | 双人落子、胜负判断、重开、战绩保存            | 撤销一步           |
| 扫雷       | 随机布雷、揭格、输赢判断、计时                | 标记、分难度       |
| 超市管理   | 添加/修改/删除商品、库存查询、文本文件保存    | 排序、销量图表     |
| 图书管理   | 图书录入、借还、查询、文件保存                | 到期提醒           |
| 车牌统计   | 从文本文件导入车牌、按地区/类别统计、图形展示 | 多条件检索         |
| 数据统计   | 从文本文件导入数据、统计平均值/最大值、图形展示 | 排序和筛选         |

车牌统计是 **文本数据统计**，不是图像识别；超市管理和数据统计项目建议使用课程发放的示例 CSV/TXT，不要求数据库。

## 四、推荐开发节奏

| 阶段              | 交付物                                 | 检查重点          |
| ----------------- | -------------------------------------- | ----------------- |
| 1. 环境与首次提交 | 运行截图、两次 commit、独立模块、CTest | Git + CMake + GCC |
| 2. 需求与模块设计 | 一页需求说明、结构体定义、模块图       | C 语言结构设计    |
| 3. 最小可用程序   | 核心逻辑可运行、文件读写可验证         | 基础功能          |
| 4. 完整版与展示   | 源码、README、演示、提交历史           | 稳定性与规范      |
